Glossary: words and abbreviations used in secbin

AES-256-GCM
The encryption your browser uses for everything you share (Advanced Encryption Standard, 256-bit keys, Galois/Counter Mode). Without the key, the stored data cannot be read.
API, API key
Application programming interface: a way for scripts and the secbin command-line tool to use secbin. An API key is the password such a script uses; it can create shares but never sign in.
Argon2id
A deliberately slow way to turn a password into a key, so that guessing passwords takes a very long time.
CAPTCHA
A check (Cloudflare Turnstile) that the visitor is a person, usually without a puzzle: most of the time it passes on its own, at most it asks you to tick a box. The letters stand for “Completely Automated Public Turing test to tell Computers and Humans Apart”.
CIDR
Classless Inter-Domain Routing: a way to write a range of network addresses, such as 10.0.0.0/8.
CLI
Command-line interface: a program you run by typing commands in a terminal.
DEK
Data encryption key: the random key that encrypts one Drive file, in your browser. It is stored sealed under your KEK.
Drive
Your file storage in secbin, with folders. Files, their names and folders are encrypted in your browser, but the Drive is not end-to-end encrypted: the server holds the keys your Drive key is made from (the MEKs), so the server, and the administrator, can open your Drive files. A copy of the stored files alone reveals nothing.
Encrypted in your browser
What every page’s footer says: what you share or keep in secbin is encrypted on your device before it is sent. Notes and file shares are also end-to-end encrypted (below). The Drive, shares of Drive files and files sent to you through a “Receive” link are encrypted with keys the server holds, so the server can decrypt them.
End-to-end encrypted
Encrypted on the sender’s device and decrypted only on the recipient’s. The server stores only data it cannot read. Notes and file shares are; the Drive, shares of Drive files and anything sent to you through a “Receive” link are not.
Escrow key
The administrator’s key of the previous release, which opened every user’s Drive in the administrator’s browser. It is used only to upgrade Drives made before this release, and removed once every Drive is upgraded.
Fragment (#fragment)
The part of a link after the # sign. Browsers never send it to the server, so the key kept there stays with you.
HKDF-SHA256
A standard way to derive several separate keys from one secret (HMAC-based key derivation with SHA-256).
IP address
Internet Protocol address: the number that identifies a device or network on the internet.
KB, MB, GB
Kilobyte, megabyte, gigabyte: sizes of files (1 MB is about a million bytes).
KEK
Key-encryption key: your Drive key. The server makes it from the MEKs and your user salt, and gives it to your browser when you open your Drive. It seals each file’s DEK, name and details.
m, h, d
Minutes, hours, days, in short durations such as “2d 3h”.
MEK
Master encryption key: the keys the server keeps (a root MEK and dated sub-MEKs, managed by the administrator) that every user’s KEK is made from. Whoever holds them can open every Drive.
Passkey
A way to sign in with your device’s fingerprint, face or screen lock instead of a password. It cannot be phished or guessed.
PDF
Portable Document Format, a common type of document file.
QR code
A square pattern that a phone camera can scan to open a link.
Receive (link)
A link that lets anyone send you files and folders into a Drive folder, without an account — and, as you choose per link, a note, a link or a credential. What they send is encrypted in their browser, to a key the server keeps under your Drive keys: like the Drive, it is not end-to-end encrypted, before or after it is received.
Recovery code
A one-time code you save when you add a passkey. Each code signs you in once, instead of your password and passkey.
Share
A note, link, credential or set of files you send with secbin. It is deleted when its views or its time run out.
TOTP, one-time code
Time-based one-time password: a six-digit code that changes every 30 seconds, used as a second sign-in step on many sites.
URL
Uniform Resource Locator: the address of a web page, a link.
View limit
How many times a share can be opened before it is deleted. For a Receive link: how many visits may start sending something — files, a note, a link or a credential (after its password and CAPTCHA); then it takes no more until you add views.
WCAG
Web Content Accessibility Guidelines, the international guidelines secbin is built to.
Zero-knowledge
The server never has the keys, so it cannot read what you store or share. This holds for notes and file shares; the Drive is the exception (see Drive).
